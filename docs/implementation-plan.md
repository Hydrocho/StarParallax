# 시차 비행 구현 기록

승인된 변경: 전체 화면 우주 풍경, 중앙 반투명 미니맵, 하단 양쪽 누르기 이동, 오른쪽 이동 버튼 위 폭탄 발사, 중앙 하단 거리 슬라이더. 크기가 서로 다른 바위가 접근하며 정해진 거리에서만 폭탄이 폭발한다.

구현: game.mjs의 독립 시뮬레이션, flight-scene.js의 고정 방향 3D 카메라, flight.js의 다중 포인터·키보드 조작과 게임 상태. 미니맵은 방향 변화만 제공한다. 연주 시차 설명은 lesson.js로 유지한다.

검증: 테스트 우선으로 폭발 거리/발사점 고정/이동/접근/일시 정지/패배/완주를 확인. 브라우저에서 실제 조준과 명중, 다중 터치, 세로·가로 반응형 배치, 설명창, 하위 경로 로딩을 검증한다.

추가 변경: 거리 슬라이더를 제거하고 누르는 시간에 따라 20~240 u(2초 최대)로 충전, 손을 떼면 발사. 다중 포인터 소유권, 키보드 길게 누르기, 취소와 일시 정지를 검증.

고정 표적 점수 모드: 바위 접근 제거, 좌우 배치 확장, 파괴한 수만큼 다른 위치의 바위를 무작위 보충. 실제 활성 플레이 시간 60초 후 종료. 일시 정지 시 카운트다운도 정지. 기존 충전 발사와 연주 시차 설명 유지.

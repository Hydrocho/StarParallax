## 조작

- 비행 시작 후 왼쪽/오른쪽 하단 버튼을 누르고 있으면 우주선이 좌우로 이동합니다.
- 바위 6개가 좌우로 넓게 흩어져 제자리에 고정되어 있습니다. 좌우로 움직여 바위를 중앙 조준점에 맞추세요. 이동 범위는 −72~72 u입니다.
- 화면 중앙의 반투명 미니맵은 현재 방향과 이동 전 잔상을 보여줍니다. 정답 거리는 표시하지 않으며 접을 수 있습니다.
- 폭탄 발사 버튼을 누르고 있는 시간으로 폭발 거리를 정합니다. 20 u부터 시작해 1초에 130 u, 2초에 최대 240 u입니다. 더 오래 눌러도 최대 거리를 유지하며 자동 발사하지 않습니다. 중앙 게이지는 현재 충전 거리를 표시합니다.
- 오른쪽 이동 버튼 위의 폭탄 버튼을 누른 뒤 손을 떼면 정면으로 발사합니다. 이동 버튼을 누른 채 다른 손가락으로 발사할 수 있습니다.
- 폭탄은 충돌 즉시 폭발하지 않습니다. 발사 때의 좌우 좌표와 폭발 거리를 유지하며, 지정한 거리에 도달할 때만 터집니다. 새로 충전할 때마다 최소 거리에서 시작합니다. 발사 후 폭발 거리는 바뀌지 않습니다.
- 바위는 폭탄이 날아가는 동안에도 움직이지 않습니다. 너무 앞/뒤에서 폭발했다면 피드백을 보고 조정하세요. 폭탄은 무제한이며 한 번에 한 발씩 발사합니다.
- 제한 시간 60초 동안 최대한 많은 바위를 파괴하는 점수 도전입니다. 바위를 부수면 다른 좌우 위치·거리·크기로 새 바위가 무작위로 나타나 항상 6개를 유지합니다. 남은 시간은 상단에 표시되며, 0초가 되면 발사 중인 폭탄과 충전을 취소하고 파괴 수·발사 횟수를 보여 줍니다. 정확히 종료 시각에 도착한 폭발은 점수에 포함합니다. 일시 정지·설명창·탭 전환 중에는 제한 시간도 멈춥니다.
- A/D 또는 ←/→: 이동. Space: 누르고 충전, 떼면 발사. 발사 버튼에 초점이 있을 때 Enter도 같은 방식입니다. P: 일시 정지. 일시 정지·탭 전환·터치 취소 시 충전은 폐기되어 오발하지 않습니다.
- 탭 전환·창 포커스 상실 시 자동 정지합니다. 안내·연주 시차 설명창을 열 때도 정지하며 닫으면 이전 비행 상태로 돌아갑니다.

## 학습 모형

이 게임에서 체험하는 것은 일반적인 시차입니다. 같은 크기로 이동할 때 가까운 바위의 방향이 더 크게 변합니다. 바위의 실제 크기가 각각 다르므로 겉보기 크기만으로 거리를 정할 수 없습니다. 카메라는 회전하지 않고 좌우로만 움직입니다.

미니맵의 점은 방향 비교 표시이며 실제 거리 좌표가 아닙니다. 관측 중 바위는 움직이지 않으므로 좌우 이동에 따른 시차를 비교할 수 있습니다. 새 바위는 좌우 −66~66 u, 거리 55~225 u 범위에 나타나며 충전 최대 거리 안에서 모두 맞힐 수 있습니다. 시차 관측의 단서를 찾는 게임으로 사용하세요.

상단의 연주 시차 설명에는 지구 공전 모형과 퀴즈가 있습니다. 별까지의 거리 슬라이더로 관측할 별의 위치를 바꿀 수 있으며, 멀수록 한쪽에 표시된 연주 시차 p와 배경별에 대한 겉보기 이동 폭이 함께 줄어듭니다. 거리 조절값은 실제 천체 거리 단위가 아닌 개념 모형의 배치 값입니다. 별 방향이 공전 궤도면에 수직인 대칭 배치에서 6개월 간격의 전체 각도 차이는 2p, 연주 시차는 p입니다. 기준선은 2 AU, 절반은 1 AU입니다. 공전 궤도 타원은 원 궤도의 투영 표현이며 하단 별의 움직임은 좌우 성분입니다.

u는 가상 거리 단위이며 천체 크기·거리·각도와 폭발 효과는 과장했습니다. 폭탄은 속도 100 u/s, 폭발 반경 4.5 u이고 바위는 구 형태의 충돌 범위로 판정합니다. 발사와 충돌은 수평 평면에서 이루어집니다. 실제 우주에서는 폭발이 이와 같이 보이지 않으며 연주 시차로 거리를 측정할 때 폭탄을 사용하지 않습니다.

연주 시차 화면의 지구 위치 슬라이더 왼쪽 ▶ 버튼은 현재 위치부터 공전을 반복 재생합니다(한 바퀴 약 12초). 다시 누르면 일시 정지합니다. 거리 슬라이더는 재생 중에도 조절할 수 있으며, 지구 위치를 직접 조절하거나 설명창을 닫거나 탭을 전환하면 재생이 멈춥니다.


### 점수 계산
- 바위당 기본 10점 + 거리 보너스(바위의 실제 깊이 10 u당 1점, 소수점 버림).
- 100 u 바위는 20점, 200 u 바위는 30점입니다. 한 폭발로 여러 바위를 맞히면 각각 합산합니다.
- 명중할 때 총 획득 점수와 거리 보너스를 표시합니다. 실패하면 점수가 없습니다.
- 점수 방식 변경 전 개수 기준 기록(v1)은 보존되지만 새 TOP 5(v2)에는 포함하지 않습니다.

### 오늘의 기록
- 1분 게임이 끝나면 기본 점수와 거리 보너스를 합산한 총점을 저장합니다. 방어막은 사용하지 않습니다.
- 상단 또는 결과 화면의 ‘오늘의 기록’ 버튼으로 오늘의 TOP 5를 확인합니다. 게임 중 열면 일시 정지됩니다.
- 기기의 현지 날짜 기준이며, 동점은 먼저 달성한 기록 순입니다. 날짜가 바뀌면 새 기록판이 시작됩니다.
- 기록은 해당 브라우저·사이트의 localStorage에만 저장됩니다. 브라우저 데이터를 지우면 삭제되며 기기 간 공유되지 않습니다.
- 추가 검증: node --test tests/records.test.mjs / python tests/records_browser_check.py


### 자동 시차 측정 HUD
- 바위가 정면에 들어오면 ‘시차 측정’ 버튼이 나타납니다. 시작하면 바위 ID와 시작 위치를 고정합니다.
- 중앙 원을 기준으로 한쪽 끝 8 u에서 관측 A, 반대쪽 끝 8 u에서 관측 B를 저장합니다. 두 체크가 모두 켜져야 측정이 완료됩니다. 관측 간격은 16 u입니다.
- 3D 관측 게이트는 이동 중 붉은색, 완료 후 초록색 체크로 표시됩니다. 화살표가 다음 방향을 안내하며, HUD에는 남은 이동 거리 또는 시차·거리만 표시합니다.
- 프레임 사이에 관측점을 지나쳐도 시선의 탄젠트를 보간해 정확한 위치의 관측값을 얻습니다. 계산식은 깊이 = (xB − xA) / (tan(각도A) − tan(각도B))입니다.
- 각도는 먼 배경의 고정 방향을 기준으로 합니다. 표시한 시차는 두 시선의 전체 각도 변화이며 연주 시차 p가 아닙니다. 게임 속 관측은 잡음이 없는 이상적인 모형입니다.
- 측정한 바위를 다시 조준하고 충전 게이지의 추천 구간(측정값 ±4 u)에 맞춰 발사합니다. 시간 안내는 반올림 값이므로 게이지를 함께 확인하세요.
- 측정 중에도 게임 시간은 흐릅니다. 일시 정지 시 관측값을 보존하고, 대상 파괴·새 게임·시간 종료·측정 해제 시 초기화합니다. 양쪽 관측점을 확보할 수 없는 가장자리에서는 측정을 시작하지 않습니다.
- 검증: node --test tests/measurement.test.mjs / python tests/measurement_browser_check.py


- 관측 게이트는 우주선의 실제 관측 x 좌표를 사용하고, 시인성을 위해 화면 비율에 맞춘 전방 거리에 띄운 안내 표식입니다. 실제 관측점은 z=0입니다. 두 시선은 실제 관측점에서 바위를 지나 먼 배경 기준면(z=-6000)까지 이어지며, 배경에 겹치는 두 위치를 색으로 구분합니다.
- 기존 2D 삼각형과 긴 설명은 표시하지 않습니다. 거리 충전 가이드는 유지합니다.

### 바위 높이와 조준
- 바위 중심은 우주선과 같은 높이(y=0)에 배치됩니다. 거리와 관계없이 화면의 같은 수평선에 보이며, 가까운 바위가 먼 바위를 가릴 수 있습니다.
- 좌우 이동 조작은 유지하며 조준점도 같은 수평선에 놓입니다. 폭탄은 선택한 전방 거리에서 바위 높이에 도달하도록 날아갑니다. 폭발과 관측선도 같은 높이를 사용합니다.

### 입체 시차 모형
- 측정 완료 시 3D 장면 위쪽에 비스듬한 입체 개념 모형을 표시합니다. 앞쪽 관측점–바위 삼각형은 청록색, 바위–배경 투영점 삼각형은 주황색 반투명 면으로 채웁니다.
- 시선은 바위를 지나 별이 있는 곡면 배경까지 연장됩니다. 배경의 두 점을 연결하여 겉보기 위치 차이를 보여 줍니다.
- 실제 관측선과 별개인 확대 모형이며, 카메라를 옮기지 않고 입체 구조를 볼 수 있도록 배치했습니다. 실제 측정 거리와 충전 가이드는 그대로 사용합니다.

### 위에서 본 측정 결과
- 측정 완료 후 비스듬한 입체 모형 대신 오른쪽 중단에 평면도를 표시합니다. 두 관측점–바위 삼각형은 청록색, 바위–먼 배경 삼각형은 주황색입니다.
- 위치는 측정한 시선과 거리로 계산하며, 거리·전체 시차·16 u 간격만 짧게 표시합니다. 측정 해제나 대상 파괴 시 도식도 사라집니다.

- 키보드 ↑: 시차 측정 시작. 자동 관측 중에는 반복 입력을 무시하며 완료 후 다시 누르면 측정을 해제합니다. 안내창·일시 정지 중에는 실행하지 않습니다.

- 중앙 기준은 원형 표식으로, 도착한 관측점은 각각 초록색 체크로 표시합니다. 양쪽이 완료되어야 결과를 표시합니다. 대칭 개념도의 직각삼각형 강조와 직각 기호는 실제 이동 방향을 따릅니다. 화면의 시차는 양쪽 관측점의 전체 관측 차이이며, 실제 연주 시차와의 대응은 대칭 배치에서 설명합니다.

### 현재 관측 완료 조건
- 중앙 원 표시는 유지합니다. 중앙에서 한쪽 8 u에 도착하면 첫 체크가 켜지고, 반대쪽 8 u까지 이동해 두 체크를 모두 켜야 거리와 충전 가이드가 나타납니다.
- 총 관측 간격은 16 u이며, 도식은 마지막 관측 방향의 직각삼각형(중앙부터 8 u)을 강조합니다.
